# TG Archive

Программа для просмотра экспортированных чатов Telegram в оформлении Telegram Desktop (Windows).
Бэкенд на Rust (Tauri 2), интерфейс — HTML/CSS/JS во встроенном WebView2.

## Запуск

Готовый файл после сборки: `src-tauri/target/release/tg-archive.exe`.

Сборка (нужны Rust и Visual Studio Build Tools с компонентом C++):

```
cd src-tauri
cargo build --release
```

Установщик (необязательно): `cargo install tauri-cli --version "^2"`, затем `cargo tauri build`.

## Возможности

- Импорт экспорта Telegram Desktop: «читаемый» HTML (`messages.html`, `messages2.html`, …), машиночитаемый JSON (`result.json`) или оба сразу (JSON имеет приоритет — он полнее).
- Полный экспорт аккаунта (`result.json` со списком чатов или `chats/chat_XXX/`) и папки с несколькими экспортами — при импорте предлагается выбрать нужные чаты.
- Добавление через меню (☰ → «Добавить чат») или перетаскиванием папки в окно.
- Файлы экспорта копируются в хранилище программы (`%APPDATA%\local.tgarchive.viewer`), исходную папку потом можно удалить.
- Личные чаты, боты, группы, супергруппы, каналы, «Избранное».
- Переименование чата (в личном чате меняется имя собеседника во всех сообщениях), переименование отдельных участников, своя аватарка чата (по умолчанию берётся фото группы из экспорта), выбор «кто я», смена типа чата, удаление.
- Сообщения: форматирование (жирный, курсив, подчёркнутый, зачёркнутый, спойлеры, моноширинный, блоки кода с языком, цитаты в т.ч. сворачиваемые, ссылки, упоминания, хэштеги, команды ботов, кастомные эмодзи), ответы с переходом к исходному сообщению, пересланные, «via @bot», правки, подписи в каналах, реакции, inline-кнопки, закреплённые сообщения.
- Медиа: фото, альбомы, видео, GIF, кружки, голосовые (с волной), аудио, файлы, стикеры (webp, анимированные tgs, видео webm), контакты, геопозиции и места (карта OpenStreetMap), опросы и викторины, списки задач, звонки, игры, счета, розыгрыши, кубики, платный контент; файлы, не вошедшие в экспорт, помечаются.
- Служебные сообщения (создание группы, вход/выход участников, смена названия и фото, закрепление и др.).
- Просмотрщик фото и видео (колесо — масштаб, стрелки — листание), поиск по чату (Ctrl+F), раздел «Информация» с общими медиа, файлами, ссылками и участниками.
- Дневная и ночная темы.

## Командная строка (для отладки)

- `tg-archive.exe --dump <папка>` — вывести разобранный чат в JSON.
- `tg-archive.exe --import <папка>` — импортировать без интерфейса.

## Ограничения

- В HTML-экспорте нет типа чата и id участников — они угадываются; при ошибке тип и «кто я» можно поменять в меню чата.
- Telegram не экспортирует превью ссылок, поэтому их нет и в программе.
- Карты загружаются из интернета (OpenStreetMap); без сети вместо карты будет только метка.
